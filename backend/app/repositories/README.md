# Слой доступа к данным

Здесь будут размещены реализации репозиториев PostgreSQL в следующих лабораторных.
Интерфейсы репозиториев должны определяться во внутреннем слое, а конкретные
адаптеры подключаться в точке сборки приложения через внедрение зависимостей.

В лабораторной №3 нет SQL-запросов, подключения к базе или фиктивного хранилища.
Проверка liveness не нуждается в репозитории.
